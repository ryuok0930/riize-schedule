# RIIZE 全球活动汇总

💜 RIIZE 全球活动汇总网页，全自动更新，部署到 GitHub Pages。

## ✨ 功能

- 📅 全球活动日历（北京时间）
- 🎫 一键跳转购票链接
- 🔔 浏览器通知提醒
- 📱 手机电脑都能用
- 🔄 **全自动更新**：每天自动检查官方公告，有新活动自动加进去

## 📁 文件结构

```
├── index.html              # 主页面
├── data.js                 # 活动数据（自动更新）
├── assets/                 # 图片资源
├── scripts/
│   └── scraper.py          # 自动爬取脚本
└── .github/workflows/
    ├── deploy.yml          # 自动部署配置
    └── scraper.yml         # 自动爬取配置
```

## 🚀 部署方法

### 1. 上传到 GitHub
- 把所有文件上传到 GitHub 仓库
- 仓库名建议：`riize-schedule`

### 2. 启用 GitHub Pages
1. 进入仓库 Settings → Pages
2. Source 选择 "GitHub Actions"
3. 保存，等几分钟就有链接了

### 3. 启用自动爬取（可选，默认已开启）
- 每天北京时间 12:00 和 20:00 自动检查
- 发现新活动自动添加到网站
- 不需要你做任何操作

## 📝 手动更新活动（爬虫没抓到的时候用）

**直接在网页上编辑：**
1. 打开 `data.js` 文件
2. 点击右上角铅笔图标编辑
3. 按照格式添加新活动
4. 拉到最下面点 "Commit changes"
5. 等1分钟网站自动更新
